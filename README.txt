# 🔁 SQL ↔ NoSQL Converter

A **Tkinter desktop application** that converts between relational (SQL) and document-based (NoSQL/JSON) data formats.

> ✅ Perfect for learning data modeling, ETL prep, or portfolio showcase.

![Demo](demo.gif) *(add screenshot/gif in real repo)*

## ✨ Features

- 📥 Import SQL `INSERT` statements or JSON data
- 🔄 Convert SQL → nested JSON (handles 1:many relationships)
- 🔄 Convert JSON → denormalized SQL (`CREATE` + `INSERT`)
- 💾 Export results to `.sql` or `.json`
- 🌓 Dark/light theme toggle
- 🧪 Sample data for quick testing
